## OTA updates use the API key

- **The example ESPHome nodes encrypt OTA with their API key.** In `winerack1aled`, `winerack1bled` and `winerack2led` the `ota:` block is now an empty `encryption:` instead of a `password:`, so uploads are encrypted with the `api: encryption: key` and plaintext uploads are refused.
- **The `*_ota_password` secrets are gone.** You can delete them from your ESPHome `secrets.yaml` once each node runs the new config.

**Re-flash each node once** with the new config, over USB or with the old OTA password. After that, OTA uploads use the API key. The integration itself is unchanged.
