## Easier wine rack setup

- **ESPHome node names is now one text box.** Type the names separated by commas, for example `winerack1aled, winerack1bled`. Before, each name had to be added as its own entry, and an unconfirmed entry made Home Assistant refuse the form with *Message malformed: Missing input nodes*. Automations and scripts you already saved keep working.
- **Rack names ignore case and spacing.** A line under **Configure → LED racks** now finds its bottles even when CellarTracker writes the Location in a different case or with extra spaces, such as `wine rack 2` for `Wine Rack 2`. Tapping a bottle in the dashboard lights it the same way.

**Already imported the blueprints?** Use **⋮ → Re-import blueprint** on both *paint a wine rack* and *wine rack controls*.
