## Rack 1 is a full 14 × 13 rectangle

Rack 1 is no longer a U. The A5–H9 section has been built in and a row N added, so the rack is now A1–N13: 14 rows of 13 bins, every row the full width.

- **Change the LED racks option.** Under *Settings → Devices & Services → CellarTracker → Configure → LED racks*, set rack 1's line to `Rack 1: 14x13` (rows × columns). Bottles filed at A5–H9 or in row N now light and no longer count as off the rack.
- **Re-flash both rack 1 boards** from `examples/esphome/winerack1aled.yaml` and `winerack1bled.yaml`. Every row is one unbroken 74-LED strand. Board 1B now drives rows H–N, seven strands like 1A, so its cables move up one port: H on O1, I on O3 and so on, with N on O8. Fuse O1 at 2 A as well.
- **Converting an old U row:** replace the jumper with a 28-LED piece for bins 5–9. `examples/HARDWARE.md` has the details, plus the new power figures (rack 1 is 1036 LEDs, 8.0 A at worst; both racks 10.1 A, 63 % of the XLG-200-12).

No change to the integration code or the blueprints. Home Assistant will show a new *Row N* light on board 1B.
