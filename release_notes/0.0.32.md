## Open in CellarTracker lands on the wine

- **The link opens the wine itself.** It now uses the same link the CellarTracker app shares (`go.cellartracker.com/wine/…`). The old link opened the CellarTracker app on a phone, but only to its start screen.

Nothing to re-flash. Bump the `?v=` on your iframe card URL if the dashboard does not pick up the change.
