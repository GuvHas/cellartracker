## Steadier rack boards

- **The boards no longer flood Home Assistant.** Each dashboard click used to switch all seven rows of a board on or off again, and each switch sent its own state message. Now only the rows that actually change are switched. On rack 2 that flood dropped the API connection and the rack stopped answering for a while.
- **Wi-Fi power saving is off** on all three example nodes. They run on mains power, so it saved nothing.
- **New diagnostic sensors** on each board: Uptime, WiFi signal, Reset reason, Access point, WiFi disconnects and API disconnects. If a rack stops answering again, these show whether the board rebooted, lost Wi-Fi or only dropped the connection to Home Assistant.

**Re-flash each ESPHome node** to get these.
