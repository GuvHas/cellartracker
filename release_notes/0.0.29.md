## Security hardening

- **The dashboard no longer accepts `?token=` in its URL.** It uses your Home Assistant session through the iframe card. If you ever put a long-lived token in a dashboard URL, revoke it under your profile's **Security** tab.
- **The refresh action can't hammer CellarTracker.** It is skipped while CellarTracker has asked the integration to back off, and within a minute of the last request. A skipped refresh is logged, not an error.
- **Rack actions check their input.** `locate_bottle` refuses a bin its rack doesn't have, and sizes are bounded on every action. Bins are read the way the boards read them, so a bin like `A1B` now counts as off the rack instead of lighting A1.
- **The paint blueprint checks events** before they reach a board. Re-import it to get this.
- **API responses are never cached**, and oversized exports and `NaN` valuations are refused.

**Re-flash each ESPHome node** to get the firmware fixes. Bin numbers can no longer overflow, the locator hold is clamped, and a malformed grid leaves the rack as it was.
