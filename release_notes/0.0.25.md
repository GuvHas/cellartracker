## A dashboard that fits the phone

- **Light racks is now a light-bulb button beside the search box.** It used to be a labelled button at the end of the sort row, which made that row too wide for a phone with larger text. It is blue when the racks follow the dashboard and grey when they don't.
- **The page can no longer scroll sideways inside its card.** The sort menu shrinks to fit, and a very long wine name wraps instead of widening its card.
