## Lighting a bottle works after the dashboard has been open a while

- **No more "invalid authentication" after 30 minutes.** The dashboard kept the Home Assistant access token it got when it loaded, and those tokens expire after 30 minutes. After that, every click to light a rack failed, and Home Assistant logged it as a failed login (it also counts toward an IP ban). The page now picks up the current token for each request and refreshes it when it has expired.

Nothing to re-flash. Bump the `?v=` on your iframe card URL if the dashboard does not pick up the change. If you use `ip_ban_enabled`, check `ip_bans.yaml` in case your proxy's address was banned.
