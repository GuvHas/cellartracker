## Dashboard fixes

- **Fits narrow phones again.** With the *Light racks* switch, the sort row could be wider than a narrow phone (or one with larger text), which pushed the whole page sideways. The switch now moves to its own line when the row doesn't fit.
- **An update now reaches every browser.** The dashboard page used to be cached by the browser after an update, so a computer could keep showing the old page, without the *Light racks* switch, even after a hard reload. The page is now checked for a newer copy every time it loads. This takes effect from the first load after this update; if a browser still shows the old page once, open `/cellartracker/cellar.html` in its own tab and reload it.
